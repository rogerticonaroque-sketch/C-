¿Qué es C++?

Primer programa en C++

La estructura mínima de un programa C++ contiene una función principal.

main.cpp 
#include <iostream>

using namespace std;

int main() {

    cout << "Hola, mundo";

    return 0;
}

Componentes

Elemento Función
#include <iostream> Permite trabajar con entrada y salida.
using namespace std; Facilita el uso de la biblioteca estándar.
int main() Función principal.
cout Muestra información.
return 0; Finaliza correctamente.

Ciclos repetitivos

Permiten ejecutar un bloque de instrucciones repetidamente.

for 

for (int i = 1; i <= 10; i++) {

    cout << i << endl;
}

while 

int numero = 1;

while (numero <= 10) {

    cout << numero << endl;

    numero++;
}

do while 

int opcion;

do {

    cout << "1. Saludar\n";
    cout << "2. Salir\n";

    cin >> opcion;

} while (opcion != 2);

break 

for (int i = 1; i <= 10; i++) {

    if (i == 5) {
        break;
    }

    cout << i << endl;
}

continue 

for (int i = 1; i <= 10; i++) {

    if (i == 5) {
        continue;
    }

    cout << i << endl;
}

Programación Orientada a Objetos

La POO permite modelar elementos mediante clases y objetos.

Clase

Plantilla que define atributos y métodos.

Objeto

Instancia de una clase.

Encapsulamiento

Controla el acceso a los datos.

Herencia

Permite reutilizar código de otras clases.

Polimorfismo

Permite diferentes comportamientos.

Abstracción

Representa solamente lo esencial.

Clase y objeto 

class Estudiante {

public:

    string nombre;
    int edad;

    void mostrarDatos() {

        cout << "Nombre: "
             << nombre
             << endl;

        cout << "Edad: "
             << edad
             << endl;
    }
};

int main() {

    Estudiante estudiante;

    estudiante.nombre = "Juan";

    estudiante.edad = 17;

    estudiante.mostrarDatos();

    return 0;
}

Constructor 

class Estudiante {

public:

    string nombre;
    int edad;

    Estudiante(string n, int e) {

        nombre = n;
        edad = e;
    }
};

Estudiante estudiante("Carlos", 17);

Encapsulamiento 

class Cuenta {

private:

    double saldo = 0;

public:

    void depositar(double cantidad) {

        saldo += cantidad;
    }

    double obtenerSaldo() {

        return saldo;
    }
};

Herencia 

class Persona {

public:

    string nombre;

    void saludar() {

        cout << "Hola";
    }
};

class Estudiante : public Persona {

public:

    int curso;
};

Polimorfismo 

class Animal {

public:

    virtual void sonido() {

        cout << "Sonido";
    }
};

class Perro : public Animal {

public:

    void sonido() override {

        cout << "Guau";
    }
};

La biblioteca estándar de C++ proporciona contenedores y algoritmos reutilizables.

vector

vector<int> numeros;

numeros.push_back(20);

for (int numero : numeros) {

#include <algorithm>

sort(

map 

#include <map>

map<string, int> edades;

cout << edades["Juan"];

Archivos

Permiten guardar información de manera permanente.

Escribir 

#include <fstream>

ofstream archivo("datos.txt");

if (archivo.is_open()) {

    archivo << "Hola C++";

    archivo.close();
}

Leer 

ifstream archivo("datos.txt");

string texto;

if (archivo.is_open()) {

    while (getline(archivo, texto)) {

        cout << texto << endl;
    }

    archivo.close();
}

Manejo de errores

Aprender a encontrar y corregir errores es una habilidad fundamental de todo programador.

❌

Error de sintaxis

El código no cumple las reglas del lenguaje.

🧠

Error lógico

El programa funciona pero entrega un resultado incorrecto.

💥

Error de ejecución

Ocurre mientras el programa está funcionando.

🐞

Depuración

Proceso de localizar y corregir errores.

Excepciones 

try {

    int edad;

    cin >> edad;

    if (edad < 0) {

        throw "Edad invalida";
    }

}
catch (const char* mensaje) {

    cout << mensaje;
}
Buena práctica: Lee siempre el mensaje del compilador antes de modificar tu código.
